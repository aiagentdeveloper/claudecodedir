Connect MCP Servers to Claude Code

8 min read · Intermediate

MCP (Model Context Protocol) servers give Claude Code real tools: GitHub, Notion, databases, browsers. One command connects a server:

claude mcp add github -- npx -y @modelcontextprotocol/server-github

Three scopes, one rule

ScopeWhereShared with team?
Local (default)~/.claude.jsonNo — current project only
Project.mcp.jsonYes — commit it
User~/.claude.jsonNo — all your projects

For team setups, add servers to .mcp.json at the project root and commit it:

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "${GITHUB_TOKEN}" }
    }
  }
}

Security basics

⚠️ Servers that fetch external content (Fetch, Puppeteer, web tools) can expose Claude to prompt injection from untrusted pages. Verify any server before connecting it — and prefer tokens via env vars, never in committed files.
  • Store tokens in environment variables referenced with ${VAR}.
  • Use claude mcp list to see what's connected.
  • For managed teams, lock down servers with allowedMcpServers in managed settings.
